# 📋 Validador de Perfil de Funcionário

Este é um projeto desenvolvido em **Python** como parte da certificação do [freeCodeCamp](https://freecodecamp.org). O objetivo principal é validar dados e informações de um perfil de funcionário usando lógica de programação.

## 🚀 Tecnologias Utilizadas

* 🐍 **Python 3**
* 🧠 Lógica de validação de dados

## 🎯 Funcionalidades

* 🔍 Verifica se os campos obrigatórios estão preenchidos.
* 🛠️ Valida o formato das informações inseridas (como e-mail, ID ou cargo).
* ⏱️ Melhora a eficiência na checagem de dados internos.

## 🛠️ Como Executar o Projeto

1. Certifique-se de ter o Python instalado na sua máquina.
2. Abra o terminal na pasta do projeto e execute o comando:
   ```bash
   python Exercícios.py
   ```
3. Insira as informações do funcionário no terminal e veja o resultado da validação!
